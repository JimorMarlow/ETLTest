# Макет для страницы усправления светодиодной лампой в умном доме

Для реализации на ESP8266/ESP32 с помощью docs/etl_wifi_setup.md необходимо разработать макет веб-интерфейс для лампы с простым управлением. При разработке будет активно использоваться моя библиотека ETL (https://github.com/JimorMarlow/ETL)

## Разработка html макера для тестового устройства

Нужно создать docs\web-wifi\qwen-webui.001.html (при следующих итерациях автоматически копировать исходный файл и увеличивать номер, все изменения в новом файле, когда завершим, я удалю лишние)

## Структура страницы

```
┌─────────────────────────────────────────────────────┐
│ [Device Icon]       [W] [M] [T]              [*]    │ ← status-bar
├─────────────────────────────────────────────────────┤
│                   Device Name                       │ ← header
│                   Description                       │
├─────────────────────────────────────────────────────┤
│                                                     │ ← power-section
│                      ┌───────┐                      │
│                     ┌┘       └┐                     │
│                     │    │    │                     │
│                     │   ─┼─   │                     │
│                     │    │    │                     │
│                     └┐       ┌┘                     │
│                      └───────┘                      │
│                                                     │
│                                                     │
│                                                     │
│                                                     │
├─────────────────────────────────────────────────────┤
│ Brightness / Яркость : 100%                         │ ← brightness-section
│                                                     │
│  [<] [●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●]  [>]   │
│                                                     │
└─────────────────────────────────────────────────────┘
```

- [Device Icon] - перенесён в status-bar из header
- [W] [M] [T] - рядом друг с другом с gap 2px, по центру между иконкой и кнопкой settings
- header - строки на всю ширину контейнера, выравнивание по центру

[W] - иконка со значком Wi-Fi, зеленая - работаем в режиме AP, синяя - подключены к другой сети, серая - ошибка подключения
[M] - иконка docs\images\icon_mqtt.svg для показа, что успешно подключились к MQTT серверу. Если нет настройки, ничего, если не удалось подключиться - серая
[T] - иконка docs\images\docs\images\icon_telegram.svg для показа, что успешно подключились к Telegram боту. Если нет настройки, ничего, если не удалось подключиться - серая

[settings-button] - вставить значок настроек (сделать заглушку для запуска настроек)
[Device Icon] - взять из docs\web-wifi\icon_hand_sensor_animate.svg
power-button - изображение кнопки включения/выключения устройства с окружностью вокруг него. Когда ON - зеленый ободок и изображение внутри как будте светится. Внутри окружности power symbol (типа IEC 60417-5009) без надписей

- Адаптирована для управления с телефона. Простой флет-дизайн в стиле iOS. 
- Управление яркостью будет пальцем по ползунку, или кнопками по бокам для более точной подстройки.
- Секция яркости выровнена по нижнему краю
- Заголовок выровнен по верху страницы
- Кнопка включения занимает остальное место в центре

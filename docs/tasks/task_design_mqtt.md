## Менеджер подключения к WiFi

Выделить из кода работы с веб-интерфейсом отдельный менеджер, который будет скрывать внутри реализацию подключения, обработку разрывов с wi-fi сетями и работой в режимах AP, STA, STA+AP.

Запланировать все работы по обособеленному менеджеру в docs\tasks\task_wifi_mgr.md

Реализация подключения к WiFi уже есть, код находится в lib\ETLTest\etl_webui.*
Разработать код менеджера в файлах:
lib\ETLTest\etl_wifi.h
lib\ETLTest\etl_wifi.cpp
Пространство имен и имя класса: etl::wifi::manager,
наследуется от \etl\etl_settings.h etl::settings::notify для обеспечения подписки на колбэки из mqtt функционала и из web-серверов для интерфейса из lib\ETLTest\etl_webui_*

После реализации менеджера wifi адаптировать код web-серверов для работы с менеджером и обновления статуса подписками на нотификации.

После того, как сервера заработают на новом wifi::manager приступать к задаче поддержки MQTT протокола.

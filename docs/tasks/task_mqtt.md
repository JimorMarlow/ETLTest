## Иконка для статуса подключенного MQTT соединения

Для иконки статуса для компактности использовать символ: 🦟 Код: U+1F99F
Также можно исопльзовать фон в виде рамки с загругляенными краями, а внутри текст, разнесенный на две стороки
[MQ]
[TT]
Так, чтобы все это занимало место одного символа, уменьшенные.

☁️ (U+2601) — классическое облако

## Соглашения и структуры данных

- Для первой реализации не использовать защищенное соединение.
- Код для ESP8266 и ESP32 разделять define для реализации API, которые отличаются на платформах.

# Разработка WebUI для клиентов на базе библиотеки ETL

Создать детальный промт для разработки сервера контента для проекта <ContentName>

Для создания веб-интерфейса устройства на базе ESP32/ESP8266 разработан инструмент 
lib\ETLTest\etl_webui*

В нем реализован сервер настройки wi-fi подключения и настройки интерфейса, реализация etl::webui::server_setup и менеджер переключения сервера контента и сервера настроек etl::webui::web_manager

Пример реализации сервера контента сделан в src\light_webui*

На базе реализации light_control_server нужно составить файл prompt_webui_content_server.md с детальным планом разработки веб-интерфейса, чтобы потом его можно было использовать в других проектах.

В начале должен находиться шаблон с со структурой данных и описанием контролируемых параметров.
Н-р: 
light_control::data::kitchen_light_t
bool power = false;                   // Состояние питания (вкл/выкл)
float brightness = 100.0f;           // Яркость [1..100], по умолчанию 100

пользователь должен будет вписать свои требования по интерфейсу и по структурам данных, создать html макет для интерфейса (например, для light-control в качестве шаблона для разработки был docs\web-wifi\qwen-webui.002.html)

а потом запустить выполнение и получить готовый к интеграции веб-интерфейс для своего проекта, реализованный на базе etl::webui::web_server_base_t

## Архитектура веб-интерфейса

### Серверы и менеджер

- **Сервер контента** (`light_control::webui::light_control_server` в `src/light_webui.*`) - основной веб-интерфейс для управления светом, лёгкий, только чтение WiFi настроек
- **Сервер настроек** (`etl::webui::server_setup` в `lib/ETLTest/etl_webui.*`) - интерфейс для настройки WiFi, UI и других параметров
- **Менеджер** (`light_control::light_webui_mgr` в `src/light_webui_mgr.h`) - переключает между серверами, чтобы тяжёлые настройки не мешали работе основного интерфейса

### Переключение серверов и WiFi

При переключении между серверами контента и настроек:
1. Вызывается `stop()` текущего сервера - **WiFi и mDNS останавливаются**
2. Вызывается `begin()` нового сервера - **WiFi и mDNS запускаются заново**

Этот момент критичен для MQTT менеджера:
- **MQTT менеджер должен отслеживать статус WiFi** через подписку на `etl::wifi::manager`
- При `stop()` сервера - WiFi отключается, MQTT должен корректно остановить соединение
- При `begin()` сервера - WiFi подключается заново, MQTT должен переподключиться к брокеру
- **Нельзя пытаться подключиться к MQTT при отсутствующем WiFi**

## Тестирование MQTT через wqtt.ru

Для проверки MQTT нужно реализовать управление светом через сервис **wqtt.ru**.

### Данные для подключения

| Параметр | Значение |
|----------|----------|
| Адрес брокера | `m1.wqtt.ru` |
| Порт | `16208` |
| Пользователь | `u_I8CLHD` |
| Пароль | (указан в настройках сервиса) |

### Топики устройств

#### Выключатель питания (Рабочая зона - Светодиодная лента)

| Параметр | Значение |
|----------|----------|
| Топик управления | `/home/guest/light/kitchen_workarea/set` |
| Топик состояния | `/home/guest/light/kitchen_workarea/state` |
| Команда включить | `1` |
| Команда выключить | `0` |

#### Регулятор яркости

| Параметр | Значение |
|----------|----------|
| Топик управления | `/home/guest/light/kitchen_workarea/brightness/set` |
| Топик состояния | `/home/guest/light/kitchen_workarea/brightness/state` |
| Мин | `0` |
| Макс | `100.0` |
| Шаг | `1.0` |
| Множитель | `1.0` |

### Интеграция с light_control::data::app()

MQTT менеджер должен:
1. **Подписаться на топики управления** (`/set`) - при получении сообщений обновлять `light_control::data::app()`
2. **Публиковать в топики состояния** (`/state`) - при изменении `light_control::data::app()` через web-интерфейс отправлять актуальное состояние
3. Связать callback'и `light_control::data::app().subscribe()` с MQTT публикацией
4. Связать входящие MQTT сообщения с `light_control::data::app().set_power()` и `set_brightness()`

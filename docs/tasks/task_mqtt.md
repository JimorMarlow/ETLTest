## Иконка для статуса подключенного MQTT соединения

Для иконки статуса для компактности использовать символ: 
☁️ (U+2601) — классическое облако
Если подключение произошло успешно, то показывать прямоугольник с закругленными краями синего цвета, а внутри символ облачка.
Для отладки добавить в src\light_webui.h иконку для MQTT со статусом, слева от статура подключения к wifi в режиме STA (в верхней части заголовка страницы, в контейнере [connection-states])

## Соглашения и структуры данных

- Для первой реализации не использовать защищенное соединение.
- Код для ESP8266 и ESP32 разделять define для реализации API, которые отличаются на платформах
пример: \ETL\src\etl\etl_espwifi.h
- Код после отладки в этом проекте будет помещен в ETL (https://github.com/JimorMarlow/ETL) вместе с инструментом webui из папки lib\ETLTest\etl_*

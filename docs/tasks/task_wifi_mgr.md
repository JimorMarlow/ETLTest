## Цель

Выделить из `etl_webui` независимый менеджер WiFi, который управляет подключениями в режимах AP, STA, STA+AP и обеспечивает обработку разрывов соединения. Менеджер должен работать автономно (без web-сервера) для поддержки MQTT.

## Контекст

Реализация подключения к WiFi уже есть в `lib/ETLTest/etl_webui_base.h/cpp`. Нужно выделить этот код в отдельный менеджер, сохранив функциональность и адаптировав для использования как web-серверами, так и MQTT менеджером.

## Этапы работ

- [ ] **Этап 1: Создание файлов и проектирование интерфейса**
  - Создать `lib/ETLTest/etl_wifi.h` и `lib/ETLTest/etl_wifi.cpp`
  - Пространство имён и класс: `etl::wifi::manager`
  - Наследовать от `etl::settings::notify` (из `etl/etl_settings.h`) для подписки на колбэки изменений настроек
  - Определить enum статусов подключения:
    ```cpp
    enum class status_t : uint8_t {
        disconnected,      // Не подключено
        connecting,        // В процессе подключения
        connected_sta,     // Подключено к WiFi (STA)
        ap_mode,           // Режим точки доступа
        ap_sta_mode,       // Одновременная работа AP + STA
        error              // Ошибка подключения
    };
    ```
  - Публичные методы интерфейса:
    - `begin()` - инициализация, загрузка настроек, автоподключение
    - `tick()` - неблокирующий цикл обработки (мониторинг, переподключение)
    - `stop()` - остановка, отключение от сети
    - `connect(ssid, password, timeout)` - подключение к STA сети
    - `disconnect()` - отключение от текущей сети
    - `start_ap(ssid, password)` - запуск точки доступа
    - `set_mode(wifi_mode_t)` - переключение режима (AP/STA/AP_STA)
    - `get_status()` - текущий статус подключения
    - `get_ip_address()` - IP адрес
    - `is_connected()` - подключено ли к внешней сети
    - `scan_networks()` - сканирование доступных сетей
  - Callback-механизм для уведомления о смене статуса (подписчики: webui, mqtt)
  - Файлы: `lib/ETLTest/etl_wifi.h`
